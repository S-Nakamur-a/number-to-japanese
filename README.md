# 数を日本語に

`99999999` が何億何万なのかを、入力した瞬間に読める形にする。

日本語は4桁ごとに位が変わる（万・億・兆）のに、数字は3桁カンマで書かれる。このズレを毎回
頭の中で変換しているコストを消すためのページ。ビルドなし・依存ゼロの静的サイト。

```
99999999  →  9999万9999
             99,999,999
             99 million 999 thousand 999
```

## 受け付ける入力

方向の切り替えはない。同じ欄に何を入れても解釈する。

| 入れられるもの | 例 |
| --- | --- |
| 区切り記号 | `99,999,999` `9999,9999` `1 234` |
| 全角 | `９９９９` `１，２３４` |
| 指数 | `1e8` `1.2E+8` |
| 単位付き | `5百万` `1.2億` `3.5兆` `1万2千` |
| ラテン接尾辞 | `5M` `2B` `1.5k` |
| 漢数字・大字 | `五百万` `千二百三十四` `壱萬` `参百弐拾` |
| 符号・小数 | `-500` `マイナス九十九` `0.5` |
| 末尾の単位 | `5円` `5メートル`（無視して警告） |

カンマは位置に関係なく取り除く。3桁区切りと4桁区切りのどちらで書かれていても同じ桁列になるため、
判別する必要がない。

読めなかったときは、元入力のどの文字が読めなかったかを指す。

## 採用した表記の規則

- **途中の桁がゼロの群は落とす。** `100000001` → `1億1`。命数法の「一億一」と同じ形で、
  `1億1万`（= 100,010,000）とは区別がつくので曖昧にならない
- **英語は3桁ごとに語を付けて展開し、丸めない。** `99 million 999 thousand 999`。
  日本語が4桁ごとに万・億を付けるのと同じ形を3桁で出している。10000 未満は語を使わず `9,999`
- **trillion より上は指数表記** `1 × 10^16`。丸めが起きたときだけ `≈` を付ける
- **命数法は無量大数（10^68）まで。** それを超えると単位混じり表記は出さず、3桁区切りと
  指数表記だけになる。位の割り当ては塵劫記系（10^52 = 恒河沙）

数値は `BigInt` で持つので桁が増えても精度は落ちない。小数は先頭100桁まで。

## 開発

```sh
npm test                  # node --test。依存パッケージなし
python3 -m http.server     # http://localhost:8000
```

`file://` で直接開くと ES module が CORS で読めないので、HTTP で配信すること。

- `src/convert.js` — 解析と整形。DOM に依存しない純関数
- `test/convert.test.js` — 境界値と、出力を自分で読み戻せることの検査
- `index.html` — 画面と DOM の配線のみ
